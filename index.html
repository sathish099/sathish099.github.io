01 / Production · LMES Academy

One platform.
Many learning journeys.

Built the student-facing LMS for courses, assignment uploads, quizzes, reports, profiles and certificate downloads. The platform serves approximately 10,000 students, including 3,000 daily active learners.

NuxtNestJSTypeScriptMySQL
Inside the implementation +

Implemented APIs and database changes within the team's architecture. Integrated existing Redis queues for background processing, PintailDB reporting queries, and Cloudflare PDF rendering for certificates. Added Playwright tests using test data across student modules.

02 / Automation & AI integration

Keeping an eye on
the registration flow.

Built scheduled Playwright checks for workshop registrations, with clear Slack alerts so the marketing team can act when something breaks.

PlaywrightCronAI APISlack
Inside the implementation +

Checks run every three hours. Page-load waits and retries address false alerts; slow pages are reported separately. An AI API turns diagnostics into explanations and suggested steps. Original failure alerts are preserved if the AI service is unavailable.
